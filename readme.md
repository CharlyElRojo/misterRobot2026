# MR Robot - AppWEB

## Descripción
Proyecto de ejemplo para demostrar el funcionamiento de una aplicación web de gestión de tareas. Permite crear, editar y eliminar tareas de forma sencilla e intuitiva.

## Instalación
1. Clonar el repositorio: `git clone https://github.com/usuario/proyecto.git`
2. Instalar dependencias: `npm install`
3. Ejecutar el proyecto: `npm start`
4. Abrir el navegador en `http://localhost:3000`

## Usos
- Gestión de tareas personales
- Organización de proyectos
- Seguimiento de actividades diarias
- Colaboración en equipo

## Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript
- React
- Node.js
- MongoDB
- Git / GitHub
